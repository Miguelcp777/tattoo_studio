# Task: The guided studio

## 1. Problem / requested change

The owner: "quiero que la experiencia sea toda guiada con pop ups", with a five-step outline (idea;
what is missing; references to remove or add; an editable summary; then work and the result with
changes and the camera) and a professional prompt drafted from the idea. Choices recorded in
ADR-0029. Evidence: INTENT.

## 2. Current behavior

A chat and a side panel with every field, a style picker, references, the master brief and the
generate button, all on one page (TASK-0064 had already moved consent to sign-in). The brief held
only the client's words. Evidence: OBSERVED.

  editable summary; it resumes after a reload.
- **REQ-002** — Step 2 asks only what is missing, as buttons; revisited, it offers every detail.

  words, overridden by the client's edit, carried in the brief and used by the worker's prompt.

  avanzado» shows the previous studio.
