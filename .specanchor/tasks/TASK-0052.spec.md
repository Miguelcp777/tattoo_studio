# Task: A failing skin plate costs no artwork, and the BFL cluster is switchable

## 1. Problem / requested change

A generation on the deployed studio failed with "FLUX ha superado el tiempo máximo de espera".
BFL's status page showed an open incident, "EU cluster increased latencies" (identified 15:56 UTC,
2026-09-29), advising a switch to `api.bfl.ai`. Offered two changes, the owner answered "sí, haz
la 1 y la 2". Evidence: INTENT, and OBSERVED (screenshot, status.bfl.ai).

## 2. Current behavior

- The graph ran `master_artwork` (OpenAI, the expensive call) before `surface_warp`, which fetched
  the skin plate from FLUX. A plate timeout therefore came after the artwork was paid for, and the
  artwork was discarded. Evidence: OBSERVED (`orchestration/pipeline.py`, `nodes.py`), reproduced
  by the studio test below against the previous order (`provider.calls == 1`).
- The worker reads `TATTOO_BFL_BASE_URL` (EU by default) but the compose file never passed it, so
  changing cluster needed a code change and a deploy. Evidence: OBSERVED (`infra/docker-compose.yml`).

## 3. Requirements

- **REQ-001** — The skin plate is settled before any artwork is drawn; a plate failure spends no
  artwork and reports its own message.
- **REQ-002** — A plate already in hand (own photo, an edit's parent plate) is used as it is.
- **REQ-003** — The BFL cluster is set from the host, EU by default, and only BFL hosts are accepted.

## 4. Acceptance criteria

- **AC-001** — Node order: skin_plate, master_artwork, stencil_trace, surface_warp, ai_blend,
  geometry_check, output_gate, assemble.
- **AC-002** — A plate that raises leaves the job failed with that message and zero artwork calls.
- **AC-003** — A supplied background is not requested again.
- **AC-004** — The compose file passes `TATTOO_BFL_BASE_URL` with the EU default; `api.eu.bfl.ai`
  and `api.bfl.ai` are accepted, any other host refused.

## 5. Decision log

- **DEC-001** — No fallback provider was added. `generation.spec.md` states "no retry/fallback" and
  leaves a fallback undecided; paying a second vendor unasked is the owner's call, not this task's.
- **DEC-002** — Switching to the global cluster does not weaken the privacy claim: the plate call
  is text-only, so no client photograph reaches BFL on either endpoint.
