# TASK-0017: Visual Internet Scout Agent and 3-Agent Triad for Historical Fidelity

## Context and Goal

Generative diffusion models lack regional cultural and religious precision unless grounded with authentic reference imagery. To solve this, a dedicated Internet Scout Agent (`VisualSearchAgent`) is integrated into a specialized 3-agent triad:
1. **Agent 1: Visual Internet Scout (`VisualSearchAgent`)**: Automatically searches and fetches authentic reference images from the internet (Wikimedia Commons, official archives) for user-requested motifs (e.g. Mare de Déu dels Desamparats, Real Senyera Coronada, Valencia CF) when not provided by the user.
2. **Agent 2: Prompt Architect (`PromptArchitectAgent` / `ResearchAgent`)**: Analyzes the scouted reference photos, enforces a 3-question ceiling for user preferences, and translates exact visual features (conical jeweled mantle, halo of star rays, tilted head, crest elements) into canonical prompt specifications.
3. **Agent 3: Visual Creator (`VisualCreatorAgent`)**: Consumes the canonical prompt and references to produce a realistic skin mockup and a 100% identical thermal transfer stencil.

## Acceptance Criteria

- **AC-001**: `VisualSearchAgent` automatically discovers high-definition reference photos for cultural, religious, and heraldic entities when the user has not uploaded their own.
- **AC-002**: Discovered reference photos are displayed in the chat interface as authentic visual anchors.
- **AC-003**: `PromptArchitectAgent` strictly derives composition details from the reference photos, preventing generic or hallucinated religious imagery.
- **AC-004**: `VisualCreatorAgent` preserves 1:1 identical linework between the skin mockup and the technical stencil.
- **AC-005**: All agent interactions, badges, and status counters remain strictly in Spanish.
