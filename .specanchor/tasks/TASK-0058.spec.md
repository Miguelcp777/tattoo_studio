# Task: Generic ideas without a reference, and Openverse as a source

## 1. Problem / requested change

On the deployed studio: "no me ha buscado ninguna imagen de mi tatuaje", "cuando clicko en buscar
referencias no hace nada". The event record showed one `scout_plan` and five `scout_judge` calls,
none failing, each keeping nothing. Offered three options, the owner chose "haz B + C": B, Openverse
as a source; C, no reference required for a generic idea. Evidence: INTENT; diagnosis OBSERVED
(owner's panel screenshot) and VERIFIED (ev-001).

## 2. Current behavior

- Commons alone is searched. For "biomechanical tattoo" it returns papers on biomechanics; the full
  Spanish sentence returns nothing. Evidence: VERIFIED (ev-001).
- With no reference the consultation adds "referencia visual" and never reaches ready; the retry
  repeats the same searches. `studio-job.referenceIds` needs one item, and the worker uses the first
  as the lineage parent and always calls the edits endpoint with the references. Evidence: OBSERVED.

## 3. Requirements

- **REQ-001** — A generic idea reaches "ready to generate" with no reference; a missing essential
  reference still blocks.
- **REQ-002** — A job may carry no reference, and the worker generates it from the brief alone.
- **REQ-003** — With no reference, the interface neither shows nor requires the references review.
- **REQ-004** — Openverse is searched as a second licensed source: licences allowing derivatives,
  no mature results, only its own thumbnails, which are the only Openverse URLs the web downloads.
- **REQ-005** — The judge rejects any image showing a person or a body part.

## 4. Acceptance criteria

- **AC-001** — The orchestrator, with a judge that keeps nothing, leaves no missing field and reaches
  `ready_to_generate` for a generic motif; the scout's message says the design will follow the
  description (`architect.test.ts`).
- **AC-002** — `studio-job` accepts `referenceIds: []` in both runtimes (`valid/no-references.json`).
- **AC-003** — A reference-free job succeeds with no analysis call; its master is `DESIGN` with no
  parent and is erased with the account (`test_a_generic_idea_is_drawn_without_references`). The
  provider posts to `/images/generations` without files and says no reference is supplied.
- **AC-004** — Through the web routes, a biomechanical idea on which Commons and Openverse find
  nothing is accepted and submitted with `referenceIds: []` (`route.test.ts`).
- **AC-005** — Openverse candidates reach the judge beside Commons; the search asks for
  `license_type=modification` and `mature=false`; a thumbnail from another host is never fetched;
  a Commons answer stands when Openverse is down; without a judge, Openverse is asked only when
  Commons is empty (`scout.test.ts`). `referenceBytes` downloads an Openverse thumbnail and refuses
  any other Openverse URL (`reference-bytes.test.ts`).
- **AC-006** — Live: the studio shows the new scout message, no reference blocker and no review
  checkbox, and «Generar diseño y plantilla» is enabled once age and permission are confirmed.

## 5. Decision log

- **DEC-001** — ADR-0026.
- **DEC-002** — Openverse restricted to `license_type=modification`: 13 results for "biomechanical
  tattoo" against 21 unrestricted and 2 with `commercial,modification`. ND licences are excluded
  because a reference shapes a new design.
- **DEC-003** — The "Buscar las referencias pendientes" button now appears only for a missing
  essential reference, the only case in which searching again can unblock anything.
