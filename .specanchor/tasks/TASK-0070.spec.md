# Task: Sexually explicit ideas are refused when they are told

## 1. Problem / requested change

«Un pene de 30 centímetros rodeado de rosas» went through the whole consultation and failed at
generation with «El proveedor no ha completado la solicitud (400)». The owner accepted the proposal:
refuse it at step 1 with a clear message, name the generator's refusal if it still happens, and
check change requests too. Evidence: INTENT; OBSERVED (screenshots); the provider's
`moderation_blocked` is INFERRED from the content, the deployed panel was not read.

## 2. Current behavior

No check on the client's text. A safety refusal of the artwork surfaced as the generic «(400)».
Evidence: OBSERVED (`StudioProvider.check`).

## 3. Requirements

- **REQ-001** — An idea asking for sexually explicit content is refused before the architect and the
  scout run when the moderation is clear (`sexual` ≥ 0.9 or `sexual/minors`), and after the
  architect when its `contentRefused` is set; the session is unchanged and the answer is 422 with
  `CONTENT_REFUSED_MESSAGE`.
- **REQ-002** — Suggestive, non-explicit motifs are not refused (rule 11).
- **REQ-003** — An edited professional description and a change request are moderated.
- **REQ-004** — A moderation failure lets the idea through; the moderation runs only with a live
  architect and the OpenAI key.
- **REQ-005** — The image model's `moderation_blocked` on artwork or edits names the refusal.

## 4. Acceptance criteria

- **AC-001** — `content-screen.test.ts`: thresholds; the endpoint call; failure and empty text; the
  screen refusing before the architect and the scout with the session untouched; the architect
  refusing; an ordinary idea and a text-less save going on; the schema requires `contentRefused`.
- **AC-002** — `live-agents.test.ts`: enabled only with a live architect and the key;
  `errorResponse` answers 422 with the message; `screenText`, used by the summary edit and the
  change request, refuses through the configured moderation and skips empty text.
- **AC-003** — `test_studio_provider.py`: `check` names a content refusal and keeps «(400)» for other
  errors.
- **AC-004** — Live: the real architect and moderation on explicit and suggestive ideas.
