# TASK-0015: Client-Centric Generation of Stencil and Hyperrealistic Body Mockup

## Context and Goal

Empower the client to seamlessly design and visualize custom tattoos via an intuitive conversation with the OpenAI GPT-6 Astra agent. The system automatically infers optimal tattoo parameters (proportions, linework, dark and dynamic color contrast) based on the client's concept and chosen body part (e.g., right side of the back, calf, chest). Once ready, the system delivers a dual visual output:
1. **The Stencil (Plantilla)**: Clean vector-like 2D line art flash template on a pure white background, ready for thermal transfer paper printing.
2. **The Hyperrealistic Body Mockup**: Studio-quality photorealistic render showing how the tattoo sits beneath the skin on the exact anatomical location chosen by the client, with rich dark blacks and vibrant accents.

## Acceptance Criteria

- **AC-001**: OpenAI GPT-6 Astra proactively infers and fills recommended tattoo parameters (`size`, `linework`, `shading`, `colour`) matching the requested anatomy without burdening the user with technical questions.
- **AC-002**: Flag `readyForGeneration` is dynamically calculated and exposed when the essential design coordinates (`subject`, `style`, `placement`) are established.
- **AC-003**: Endpoint `POST /api/generate` produces concurrent dual outputs: a clean line-art stencil (thermal-ready, no skin) and a hyperrealistic anatomical mockup on the specified body part.
- **AC-004**: Interactive client modal `TattooPreviewModal` provides comparative side-by-side view, single-asset inspection with zoom, and high-definition asset download.
- **AC-005**: All UI labels, prompt communication, and status indicators remain strictly in Spanish.
- **AC-006**: Automated test coverage verifies parameter inference, endpoint behavior, and error handling.
