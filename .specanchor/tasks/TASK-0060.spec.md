# Task: The skin plate library

## 1. Problem / requested change

The owner: "no sería mejor crear esas imágenes de las partes del cuerpo de hombre y mujer y tenerlas
guardadas sin necesidad de tener que crearlas cada vez?"; then "si, haz la biblioteca de fotos de
piel". Evidence: INTENT.

## 2. Current behavior

Every design without the client's own photograph generated its plate: a paid call and a wait, and a
refusal by the provider's safety system for some zones (TASK-0059). Evidence: OBSERVED.

## 3. Requirements

- **REQ-001** — A reviewed plate for each of the 26 zones and both bodies is committed.
- **REQ-002** — The studio uses the library plate when it has one, and generates otherwise.
- **REQ-003** — A left-side design gets the plate mirrored, except on the centre line; a brief with no
  body gets one of the two, the same for every version of the design.
- **REQ-004** — The library is built by a runner that never pays twice for a plate on disk and waits
  out a rate limit.
- **REQ-005** — A woman's chest and sternum plates are described with what covers the breasts.

## 4. Acceptance criteria

- **AC-001** — `test_the_committed_library_is_complete`: 52 files, each 1024 × 1536.
- **AC-002** — `test_a_library_plate_is_used_before_one_is_generated`: a generation whose provider
  would fail on a plate succeeds with the library's plate as its background.
- **AC-003** — `test_the_library_serves_mirrors_and_declines` and
  `test_no_body_named_is_one_body_for_every_version_of_a_design`.
- **AC-004** — `test_building_skips_what_exists_and_waits_out_a_failure`.
- **AC-005** — `test_a_womans_chest_is_described_with_what_covers_it`.

## 5. Decision log

- **DEC-001** — ADR-0027.
- **DEC-002** — OpenAI at `medium`, the production plate call, rather than `high`: the library
  replaces exactly what production drew, and a plate can be regenerated one at a time later.
- **DEC-003** — The first build drew a bearded man for "chest, feminine" and an ambiguous torso for
  "sternum, feminine". `BODY_VIEWS` names the bandeau top and the sports bra; both were regenerated.
