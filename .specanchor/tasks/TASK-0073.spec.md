# Task: The size the client states and confirms is the size printed (audit UX-01)

## 1. Problem / requested change

External audit `INFORME.md` (2026-10-01), finding UX-01 (high): «15 cm de ancho y 30 cm de alto»
was not read, the studio's proposal (140 × 280 mm) replaced it, and the worker could reassign
reference-anatomy millimetres on a whole-zone request without the client confirming them. The owner
asked to apply the audit's recommendations. Evidence: INTENT; OBSERVED by the auditor in production;
OBSERVED in code (`researcher.ts`, `app/studio.py`).

## 2. Current behavior

- `extractPreferences` read only `N x N cm|mm`.
- `Studio.generate` set `brief.size = zone_millimetres` whenever a whole-zone intent was read, in
  the idea or a change request, and `reposition` did the same for a phrase.

## 3. Requirements

- **REQ-001** — `statedSize` reads compact (`15 x 30 cm`, `15cm x 30cm`, `15 por 30 cm`, mm),
  labelled (`de ancho`/`de alto`/`de largo`, either order, decimals with a comma, one unit shared),
  and keeps a single stated dimension as the client's (`stated`), proposing only the other and
  saying so in the summary.
- **REQ-002** — The worker never changes the accepted millimetres of an initial design; a
  whole-zone idea covers the zone on the skin at the accepted size.
- **REQ-003** — In a change request, only the explicit «Ocupar toda la zona» control
  (`coverage: "full"`) changes print millimetres; it is confirmed in a dialog that shows the current
  and the approximate new size. A placement-only whole-zone sentence is answered with how to use
  the control (422) and queues nothing; a mixed one redraws at the accepted size.

## 4. Acceptance criteria

- **AC-001** — `stated-size.test.ts`: twelve phrasings to millimetres; single dimensions; no unit;
  the audit's calf sentence reaches the summary as 150 × 300 mm, not proposed; a zone change keeps
  the stated dimension.
- **AC-002** — Worker: the initial whole-calf idea keeps 150 × 500 mm in the result and the SVG;
  the phrase is refused with the control's name and no provider call; the mixed request keeps the
  size; the control resizes and re-exports (existing ADR-0008 assertions).
- **AC-003** — Web: `zone-size.test.ts`; the modal's confirmation dialog.
