# Correct ignored mockup scale

Observed: uncalibrated preview always defaults to 36% photograph width, irrespective of
millimetres. Editing preserves placement, so requests to fill the calf only redraw artwork.

- REQ-001 / AC-001: automatic generated-calf placement responds to brief dimensions using
  an explicitly illustrative 400 mm vertical frame assumption and safe image bounds.
  Manual and calibrated placement remain authoritative. No claim of measured anatomy.
- REQ-002 / AC-002: recognize a bounded set of Spanish whole-tattoo size requests, including
  'que ocupe casi todo el gemelo', and offer explicit larger/smaller/full preview controls.
  Pure placement revisions reuse master and stencil bytes/identity; no artwork provider call.
- REQ-003 / AC-003: coverage changes produce owned versioned mockups on the same saved
  background. Legacy missing backgrounds may require a new one. Physical PDF dimensions
  do not change. Calibrated photos reject visual-only size changes rather than mislabel scale.
- REQ-004 / AC-004: tests cover increased pixel bounds, unchanged artwork/stencil, body
  ownership, explicit and inferred instructions; inspect rendered controls and a real local
  recomposition. Preserve pre-existing dirty tree and original proposals.
