# Task: A design is the result only of its own consultation (audit UX-02)

## 1. Problem / requested change

Audit finding UX-02: reopening a Valencian consultation showed «Tu diseño está listo» and «Ver
diseño y descargar» opened an older dragon from the history. `refreshVersions` restored the newest
stored design whatever consultation was open. Evidence: OBSERVED by the auditor; OBSERVED in
`lib/opening.ts` and `app/page.tsx`.

## 2. Current behavior

After a restore without a running job, the newest design became the page's `artifact`, and every
"has a design" gate read `Boolean(artifact)`.

## 3. Requirements

- **REQ-001** — With a consultation open, only a design whose `briefId` is that consultation's id is
  restored as its result; others stay in «Tus diseños», where the client opens them deliberately.
- **REQ-002** — The "design ready" gates of both modes count only such a design.
- **REQ-003** — A generation that failed while the page was closed says so on return, in plain words.

## 4. Acceptance criteria

- **AC-001** — `opening.test.ts`: the audit case (Valencian consultation, dragon design) is not
  current; the consultation's own design is; with no consultation, the opened design is shown.
