# Task: Web Consultation Surface and Reference Image Ingestion

## 1. Problem / requested change

`packages/consultation` provides the consultation state machine and OpenAI GPT-6 Astra provider
(TASK-0003), but `apps/web` remains a static placeholder shell without an interactive UI or BFF
route. Users cannot currently interact with the tattoo consultation agent, cannot upload reference
photos from the browser, and cannot see their `TattooBrief` take shape in real time.

## 2. Current behavior

- `packages/consultation` is implemented, tested and verified offline with 5 tests passing.
- `apps/web` is a skeleton with one placeholder route and disclaimer text (TASK-0001).
- No API route exists to mediate consultation turns between the browser and the consultation engine.
- No UI components exist for chatting, uploading reference images, or inspecting the brief contract.

## 3. Desired behavior

- A Next.js API route (`/api/consultation`) that delegates consultation turns to `@tattoo/consultation`.
  Uses `OpenAIAstraProvider` when `OPENAI_API_KEY` is configured, falling back to
  `FixtureConsultationProvider` for offline development and automated tests.
- A client-side reference image uploader supporting drag-and-drop or file selection, validating
  image MIME types (`image/jpeg`, `image/png`, `image/webp`) and converting them to base64 data URLs.
- A responsive, modern consultation interface allowing interactive conversation turns.
- A real-time `TattooBrief` tracker displaying the progressively filled slots (style, linework,
  shading, colour, placement, size in mm) and contract validation status.
- Unconditional display of mandatory disclaimers (`WEB-INV-003`) and an anti-mimicry banner
  warning if a living artist is named (`PROD-INV-004`).

## 4. Scope

- `apps/web/package.json`: Add workspace dependencies to `@tattoo/contracts` and `@tattoo/consultation`.
- `apps/web/src/app/api/consultation/route.ts`: BFF consultation turn handler.
- `apps/web/src/app/api/consultation/route.test.ts`: Route automated tests.
- `apps/web/src/components/ReferenceUploader.tsx`: Image upload and preview component.
- `apps/web/src/components/BriefTracker.tsx`: Contract slot inspector.
- `apps/web/src/app/globals.css`: Dark-mode studio styling.
- `apps/web/src/app/layout.tsx`: Root layout with styling.
- `apps/web/src/app/page.tsx`: Consultation interactive page.
- `.specanchor/modules/web.spec.md`: Update specification.
- `.specanchor/spec-index.md`: Register task.

## 5. Out of scope

- Generating visual images/mockups (handled downstream by worker generation engines via `ARCH-INV-001`).
- User authentication and persistent database sessions (in-memory state during client session).
- Direct body-photo processing for mockup warping (handled by `mockup` / `safety` modules).
