# Task: Widen the style vocabulary and share the reference anatomy

# 1. Problem / requested change

Owner request, 2026-09-22: the agent should fill style, zone and colour from what the client
writes, and default the size from qualitative words when no measurement is given. Implements
ADR-0011. The first of three tasks; the style library and the master-prompt review gate follow.

## 2. Current behavior

- `researcher.ts` already extracts style, zone, side, orientation and colour from free text.
  Evidence: OBSERVED. Size extraction handles only `NNxNN mm|cm`.
- `styleName` holds ten entries. `tribal` is absent, and `tribal_freehand` exists solely as the
  out-of-vocabulary rejection fixture. Evidence: OBSERVED.
- Reference spans live in `services/worker/mockup/anatomy.py`, unavailable to the TypeScript that
  assembles the brief. Evidence: OBSERVED.

## 3. Desired behavior

Six mainstream styles are accepted. A qualitative size resolves against the named zone using the
same numbers the worker uses.

## 4. Scope

`contracts/schemas/tattoo-brief.schema.json`, `contracts/reference/body-zones.json` (new),
`contracts/src/index.ts`, `contracts/python/scripts/generate.py`, the regenerated artifacts,
`contracts/python/tests/test_corpus.py`, `packages/consultation/src/agents/researcher.ts` and its
tests, `services/worker/mockup/anatomy.py`, `services/worker/flash/prompt.py`, `.prettierignore`.

## 5. Out of scope

The style image library and the master-prompt review gate: separate tasks. No change to how a
brief is validated, to the worker's pipeline, or to the UI.

## 6. Affected anchors

ADR-0011 (implements), ADR-0004 (single source of truth — the reason the table moved),
ADR-0008 (supplies the spans), CONSULT-INV-003 (vocabulary stays closed), CONSULT-INV-004.

## 7. Requirements

- **REQ-001** — `styleName` gains `tribal`, `geometric`, `watercolour`, `new_school`, `chicano`,
  `biomechanical`, and both runtimes' artifacts are regenerated from the schema.
- **REQ-002** — Each added style has a Spanish label and free-text recognition.
- **REQ-003** — Each added style has a visual-characteristics phrase in `flash/prompt.py`.
- **REQ-004** — Reference spans and size scales are canonical in `contracts/reference/`, copied
  byte-identically into the Python package, read by the worker and imported by TypeScript.
- **REQ-005** — A qualitative size resolves as a fraction of the named zone. No zone means no
  proposal. An explicit measurement wins.
- **REQ-006** — The vocabulary stays closed: an unknown style is still rejected.

## 8. Acceptance criteria

- **AC-001** (REQ-001) — Generated TypeScript and Python artifacts contain all sixteen entries
  and match the schema under the codegen reproducibility check.
- **AC-002** (REQ-002) — Each added style is recognised from a representative Spanish phrase, and
  the original ten still are.
- **AC-003** (REQ-003) — The existing vocabulary-coverage test passes for all sixteen.
- **AC-004** (REQ-004) — Byte identity between canonical and packaged copies; every `bodyPart`
  has a span; every span lies within the contract's millimetre bounds and every scale in (0, 1].
- **AC-005** (REQ-005) — `grande` on `upper_back` exceeds `grande` on `wrist_inner` by more than
  threefold; small < medium < large; an explicit measurement overrides the word; an unknown zone
  yields nothing.
- **AC-006** (REQ-006) — `tribal_freehand` is still rejected.

## 9. Design approach

See ADR-0011. The one structural move is promoting the anatomy table from worker source to
shared contract data, reusing the copy-and-assert-byte-identity mechanism the schemas already
use rather than inventing a second one.

## 10. API / data / UI impact

A widened enum, which is backward compatible: every previously valid brief remains valid. One new
canonical data file and its packaged copy. No route or schema-shape change.

## 11. Migration and backward compatibility

None required. No stored brief becomes invalid.

## 12. Test plan

Contract tests for the reference data; TypeScript tests for recognition and size resolution;
the existing vocabulary-coverage test for the phrases.

## 13. Risks and rollback

The six new style phrases have never been rendered, so their quality is unverified — the same
exposure TASK-0004 found for `american_traditional`, which needed rewriting after a live probe.
Rollback is reverting the enum, which would invalidate any brief already recorded with a new
style.

## 15. Decision log

- **DEC-001** — The table moved rather than being copied. A second hand-maintained table is the
  drift ADR-0004 exists to prevent, and a size is exactly the number nobody re-checks.
- **DEC-002** — `dotwork` and `minimalist` were not added. The first is already a
  `shading.technique`; the second is `fine_line`. Adding either would give two ways to say one
  thing.
- **DEC-003** — The test asserting a Spanish phrase per style found all six omissions the moment
  the enum widened. Recorded because it is the second time this task's own tests caught a real
  defect before a human did.
- **DEC-004** — The word-boundary anchors in the size patterns were silently turned into
  backspace control characters by a layer of shell-and-Python quoting, so every qualitative size
  returned nothing. Found by the tests written for AC-005, not by review, and fixed by writing
  the file directly. A test asserting no control characters would not be unreasonable.
