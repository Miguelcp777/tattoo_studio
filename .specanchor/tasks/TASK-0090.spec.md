# Task: Make sure the image model draws the design, not a body

## 1. Problem / requested change

The owner: «es como que ha tatuado un muslo dentro de mi muslo, es un problema de interpretación
del prompt, debemos poner medidas para asegurar que el prompt está bien interpretado». A
biomechanical design for the thigh came back as a thigh with the tattoo on it, on a grey backdrop;
the stencil traced the leg's outline and the mockup showed a leg within the leg. Evidence: INTENT;
OBSERVED (screenshots). The cause is INFERRED from the prompt: the brief names the zone and the
artwork prompt never forbade drawing it.

## 2. Current behavior

The artwork prompt asked for a flat design on white; nothing checked what came back.

## 3. Requirements

- **REQ-001** — Every artwork prompt asks for the design alone, as on flash paper, never a body,
  limb, skin, person or a tattoo on skin; the placement only gives shape and proportions.
- **REQ-002** — `StudioProvider.check_artwork` asks the vision model (strict JSON) whether the
  artwork depicts a body or skin and whether the requested subject is present; an unavailable or
  ambiguous answer is no verdict.
- **REQ-003** — `make_artwork` reviews every artwork: a misread one is drawn once more with a
  correction naming what went wrong (an edit is repeated as asked); a second misread fails the job
  with `ARTWORK_MISREAD`, in plain words; no verdict lets the artwork through.
- **REQ-004** — Rule 10 of the consultation prompt: the professional description describes the
  design as drawn on paper, the zone only as the shape to fill, never the body or skin.
- **REQ-005** — The panel names the review calls «Revisión del dibujo».

## 4. Acceptance criteria

- **AC-001** — Generation tests: the prompt carries the instruction and the correction; strict
  parsing; the vision request carries the subject; a failed request is no verdict.
- **AC-002** — Pipeline tests: redraw with a correction; failure after two misreads with the plain
  message; no verdict passes.
- **AC-003** — `system-prompt.test.ts`.
- **AC-004** — Live: the real vision model on a real mockup and a real flat design.
